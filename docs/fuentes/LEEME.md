# Fuentes de referencia (texto extraído)

Texto extraído de los documentos de referencia del proyecto, para que las sesiones de desarrollo puedan leerlo.
Son material de consulta: contienen valores de ejemplo hasta que alguien con criterio médico los valide.

| archivo | contenido |
|---|---|
| `nasa_std_3001_limites_vs_hrp.txt` | NASA-STD-3001 Vol. 1 Rev. C frente a cifras del HRP (norma, observaciones) |
| `datos_medicos.txt` | Guía interna: arquitectura, biomarcadores, umbrales, contramedidas, niveles de atención |
| `salud_astronautas_y_monitoreo.txt` | Peligros, sistemas del organismo, radiación y efectos en la electrónica |
| `variacion_dosis_efectiva.txt` | GCR, bandas de presión arterial, examen ASCAN, pulso, temperatura, sueño, escalas de ánimo |

Las páginas web de NASA HRP y CSA (peligros, riesgos, investigación) no se guardaron como archivo.
