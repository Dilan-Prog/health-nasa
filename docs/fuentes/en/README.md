# Reference sources (extracted text) — English translation

English translation of the project's reference documents. The Spanish originals are in the parent folder (`docs/fuentes/`) and are the versions the application and the knowledge sheets cite; these translations are provided for reviewers.

The text was extracted from the project's reference documents so development sessions can read it. It is reference material: it contains example values until someone with medical judgment validates them. The standard's requirements are paraphrased in the project's reference document; they are not verbatim quotes of NASA-STD-3001, which is published in English.

| file | content |
|---|---|
| `nasa_std_3001_limites_vs_hrp.txt` | NASA-STD-3001 Vol. 1 Rev. C versus HRP figures (standard requirements, observations) |
| `datos_medicos.txt` | Internal guide: architecture, biomarkers, thresholds, countermeasures, care levels |
| `salud_astronautas_y_monitoreo.txt` | Hazards, body systems, radiation and effects on electronics |
| `variacion_dosis_efectiva.txt` | GCR, blood pressure bands, ASCAN exam, heart rate, temperature, sleep, mood scales |

The NASA HRP and CSA web pages (hazards, risks, research) were not saved as files.
